# Customer_Behavior
# Customer Shopping Behavior Analysis (SQL Project)

## Project Overview

This project focuses on analyzing **customer shopping behavior** using structured transactional data. The objective is to uncover meaningful insights related to customer purchasing patterns, spending behavior, product preferences, and revenue drivers. The analysis is performed primarily using **SQL**, making it suitable for data analyst roles and interview discussions.

This repository contains a CSV dataset and SQL-based analytical logic that demonstrates real-world data analysis skills such as data cleaning, aggregation, segmentation, and KPI generation.

---

## Dataset Description

**File:** `customer_shopping_behavior.csv`

The dataset represents customer-level shopping transactions and includes information such as:

* Customer identifiers
* Product or category details
* Purchase quantities
* Transaction values
* Order or purchase dates
* Demographic or behavioral attributes (if available)

The dataset is structured to support behavioral analysis, trend identification, and performance measurement.

---

## Key Objectives

* Understand customer purchasing patterns and frequency
* Identify high-value and repeat customers
* Analyze product and category-level performance
* Calculate key business metrics (KPIs)
* Support data-driven decision-making using SQL

---

## Analysis Performed

The project includes the following analytical components across SQL, Jupyter Notebook, and Power BI:

* **Data Cleaning & Validation**

  * Cleaned and validated raw CSV data using SQL and Jupyter Notebook
  * Handled missing values, duplicates, and data-type inconsistencies

* **Exploratory Data Analysis (Jupyter Notebook)**

  * Performed exploratory analysis using Python to understand distributions and trends
  * Validated SQL outputs through notebook-based analysis

* **Customer Segmentation (SQL)**

  * Identified repeat customers, high-value users, and low-engagement segments
  * Analyzed purchase frequency and spending behavior

* **KPI Calculation (SQL)**

  * Total Revenue
  * Average Order Value (AOV)
  * Purchase Frequency
  * Customer Lifetime Value (CLV)

* **Data Visualization & Reporting (Power BI)**

  * Designed interactive dashboards to present customer behavior insights
  * Visualized sales trends, category performance, and customer segments for stakeholders
